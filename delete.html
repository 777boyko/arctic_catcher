What data does Arctic Catcher collect?

Arctic Catcher does not require users to create an in-app account. Sign-in can be performed via OAuth (e.g., Google Play Games / Google Sign-In) strictly to identify a player session and enable basic game features.

We do not collect sensitive personal data (such as phone numbers or passwords). Any OAuth tokens are handled by the provider and are not stored as user passwords by DULAB TOV.

When would deletion be needed?

Even if the app stores little to no personal data, you can still request deletion of any data that may exist (for example: a player identifier, game progress stored on a backend, or support communications).

  • Typical OAuth-related identifiers: provider user ID / player ID
  • Typical game data (if enabled): progress, achievements, cloud saves
  • Support requests (if sent): message content you submit
Tip: you can find your Player ID in the app’s settings (if shown) or attach a screenshot.
