Arctic Catcher — by DULAB TOV

Overview

Arctic Catcher does not require users to create an in-app account. Sign-in may be performed via OAuth (for example, Google Play Games / Google Sign-In) to identify a player session and enable game features.

DULAB TOV does not collect passwords or phone numbers. Any authentication credentials are handled by the OAuth provider.

Data that may be associated with OAuth sign-in

  • Provider user identifier (e.g., Play Games player identifier)
  • Basic profile information made available by the provider (e.g., display name, avatar), if enabled
  • Game data linked to the identifier (e.g., progress, achievements), if stored

Deletion

You can request deletion of any data associated with your OAuth account identifier. We may ask for verification to ensure the request is authorized.

DULAB TOV will process deletion requests as soon as reasonably possible after verification.
